# Overtime – IPTV player for Windows

Kotlin Multiplatform project (JVM target only for now, structured so an Android target can be added later).
Compose Multiplatform UI, libVLC playback through vlcj 4.x. libVLC is bundled into the app image (`bundleVlc` task copies the build
machine's VLC 3 64-bit into `app/resources/vlc`, minus plugins/gui; the plugin cache is rebuilt after
`createDistributable`); `VlcPlayer` puts it on `jna.library.path` so it wins over an installed VLC.
Unexpected errors are written to `%APPDATA%\Overtime\error.log` (`ErrorLog`).

## Layout

- `composeApp/src/commonMain` – models, M3U/Xtream/EPG data layer, `AppViewModel`, all UI.
- `composeApp/src/jvmMain` – `Main.kt` (window + shortcuts), `VlcPlayer` (frames rendered to an `ImageBitmap`
  via a vlcj callback surface, no AWT interop), StAX XMLTV parser, file store in `%APPDATA%\Overtime`.
- Platform hooks are `expect`/`actual` declarations in `data/Platform.kt`.

## Conventions

- Material 3 Expressive (material3 alpha, `MaterialExpressiveTheme` + `MotionScheme.expressive()`), dark only.
  Full colour scheme in `ui/Theme.kt`; accent and sidebar colours are user settings derived there.
  Expressive opt-ins are enabled for all source sets in `composeApp/build.gradle.kts`.
- Component conventions: buttons and icon buttons pass `shapes = ...Defaults.shapes()` (press morph);
  single-choice selectors use `ConnectedChoiceGroup`; the sidebar is a navigation drawer
  (`NavigationDrawerItem` pills, `surfaceContainerLow`); player controls live in the floating pill
  toolbar; both volume bars use `VolumeSlider`. Shared pieces are in `ui/Components.kt`.
- Dialogs go through `DialogFrame` in `ui/Dialogs.kt` (scrollable body, fixed action row).
- Full-window pages: Guide (`ui/GuideScreen.kt`, G) and Movies & series (`ui/LibraryScreen.kt` +
  `LibraryModel`, L; Xtream only). On-demand titles play directly (no rewind recorder) with a seek bar.
- Xtream JSON is inconsistent across panels: read it with the lenient helpers in `XtreamApi`
  (`str`, `obj`, `firstOf`), never `jsonPrimitive.content` (JSON null would become "null").
- UI review without VLC: `OVERTIME_SCREENSHOTS=<dir> .\gradlew :composeApp:jvmTest` renders the main
  screens to PNGs with demo data (`ScreenshotTest`).
- State lives in `AppViewModel` as `StateFlow`s; composables only `collectAsState()`.
- Persisted JSON uses kotlinx.serialization with `ignoreUnknownKeys` so old files keep loading.
- Build: `.\gradlew :composeApp:run`. Package: `.\gradlew :composeApp:packageMsi`.
- App icon is generated by `python tools/make_icon.py` (Pillow) into `composeApp/icons/overtime.ico`
  (exe/installer) and `composeApp/src/jvmMain/resources/overtime_icon.png` (window/taskbar).
  Design: Material Icons Rounded "live_tv" (SVG in `tools/symbols/`, same glyph as the Android app) in
  #0A0A0B (strokes thickened a little) on a #8AD0F2 rounded square with a flat 45° long shadow to the
  bottom-right; sizes up to 32 px get a slightly larger glyph (the shadow shows at every size). `--android <res>` also writes
  Overtime Android's launcher layers. Edit the script,
  not the images.
